# 金代定窑白釉六花口碗

- ID：DY-2009-207
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1④：103
- 完残程度：已复原
- 器类：碗
- 口沿：尖唇，侈口，六花口
- 腹部：上腹斜直，下腹曲收
- 底足：矮圈足较薄，挖足到肩
- 整体造型：侈口六花口曲腹圈足碗（F型），内壁饰六道凸线纹
- 尺寸（厘米）：高 5.8，口径 13.5，足径 4.8
- 胎质：细腻坚致，有少量黑色杂质　胎色：白胎泛灰
- 釉色：白釉泛青灰，较光亮，有泪痕泛青绿色
- 施釉范围：内外满釉，芒口
- 釉面特征：外腹及底积釉处可见较多小气泡，釉面较多褐点杂质，有蜡泪痕
- 纹饰：花口对应处内壁饰六道凸线纹，内底压环；器外口沿下有较浅凸弦纹和较深凹弦纹，外腹拉坯所成弦纹较明显
- 成型：拉坯成形　装饰技法：素面（压环、弦纹）　施釉技法：　装烧：芒口覆烧（支圈覆烧）
- 研究说明：六花口碗内壁六道凸线、内底压环，为涧西区金代后期定窑细白瓷常见形制。
