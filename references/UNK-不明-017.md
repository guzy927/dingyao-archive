# 定窑白釉刻「徐六师记」款皮囊壶

- ID：UNK-不明-017
- 来源文献：定瓷雅集：故宫博物院珍藏及出土定窑瓷器荟萃 (故宫博物院)
- 时代：唐　出土年份：不明
- 出土地点：传世品
- 出土单位：
- 完残程度：完整
- 器类：壶（皮囊壶）
- 口沿：直口
- 腹部：矮身，垂腹
- 底足：平底
- 整体造型：通体扁圆，提梁高隆；属矮身横梁式皮囊壶
- 尺寸（厘米）：高 12.5，口径 2.2，足径 12.5
- 胎质：　胎色：
- 釉色：白中泛青
- 施釉范围：施釉近底，底部露胎
- 釉面特征：
- 纹饰：腹部三道仿皮囊缝合的凸棱
- 成型：　装饰技法：刻款　施釉技法：　装烧：
- 研究说明：底部露胎处阴刻「徐六师记」四字款。考古发现的皮囊壶分扁身单孔、扁身双孔、扁身环梁、圆身环梁、矮身横梁五型，此壶属矮身横梁型，唐代已出现；皮囊壶又称鸡冠壶、马镫壶，原型为北方游牧民族皮质容器，陶瓷品系对原形的模拟，并无实用功能。
