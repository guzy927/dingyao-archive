# 辽代定窑银盖白瓷葫芦瓶

- ID：UNK-2015-009
- 来源文献：内蒙古多伦县小王力沟辽代墓葬_盖之庸
- 时代：辽代中期　出土年份：2015
- 出土地点：内蒙古自治区锡林郭勒盟多伦县蔡木山乡铁公泡子村小王力沟辽代墓地
- 出土单位：M2（标本M2：22－2）
- 完残程度：可修复
- 器类：葫芦瓶
- 口沿：瓶身母口；银盖子口，丝蔓钮
- 腹部：瓶身上半部斜肩，腹部向下斜收；下半部为球形腹
- 底足：假圈足
- 整体造型：整体呈葫芦状
- 尺寸（厘米）：高 36，口径 4.7，足径 11
- 胎质：坚硬，瓷化程度高　胎色：
- 釉色：白釉
- 施釉范围：
- 釉面特征：
- 纹饰：瓶身上半部：肩部饰双重覆莲纹，腹部饰三重仰莲纹；瓶身下半部：上方饰三重覆莲纹，下方饰四重仰莲纹
- 成型：胎模成形（原文：均于胎模上剔刻出花纹）　装饰技法：剔刻　施釉技法：圈足内正中施釉后刮去，再刻款　装烧：
- 研究说明：圈足内正中施釉后刮去，再在其上刻正书"官"字款。银盖锤揲、焊接成形，盖面隆起，其上錾刻莲叶纹，边缘上翻卷起呈五角形。原文结语：定窑器多有"官"字款，此瓶属定窑。
