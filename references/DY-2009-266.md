# 金代定窑黄釉碟

- ID：DY-2009-266
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：499
- 完残程度：仅存口部及腹部，残高1.6厘米
- 器类：碟
- 口沿：敞口
- 腹部：浅曲腹
- 底足：
- 整体造型：敞口浅曲腹碟，内底刻圆
- 尺寸（厘米）：高 1.6，口径 ，足径 
- 胎质：坚致　胎色：白胎
- 釉色：黄釉，较光亮
- 施釉范围：内外满釉，芒口
- 釉面特征：内壁施釉不均，器外下腹处有环状积釉带，积釉处泛青，釉面少量褐点杂质
- 纹饰：内底刻圆
- 成型：　装饰技法：刻花（刻圆）　施釉技法：　装烧：覆烧（芒口）
- 研究说明：黄釉碟为涧西区黄釉瓷中数量最少的器类（仅1件）。
- 溯源备注：黄釉碟标本，无图版。
