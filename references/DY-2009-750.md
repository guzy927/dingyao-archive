# 定窑白釉敞口盘（Dg型Ⅲ式）

- ID：DY-2009-750
- 来源文献：高美京《定窑研究》2015（修订版）未设密码
- 时代：　出土年份：2009
- 出土地点：河北曲阳定窑遗址
- 出土单位：JCAT2F4:24
- 完残程度：完整
- 器类：盘
- 口沿：尖圆唇，大敞口六花口
- 腹部：折腹，上腹斜直微内曲，下腹平收微下斜
- 底足：矮圈足，足端很窄，挖足过肩
- 整体造型：覆烧；满印花
- 尺寸（厘米）：高 4.1，口径 18.8，足径 5.5
- 胎质：较薄，较坚致　胎色：白微泛灰
- 釉色：白釉泛灰青，积釉处呈青黄色
- 施釉范围：满釉（芒口）
- 釉面特征：外壁下腹有垂釉痕；足底施釉前粘少量杂质
- 纹饰：内壁满印花，布局为口沿下方一圈八组云气纹，云气纹下满印缠枝花卉
- 成型：　装饰技法：印花　施釉技法：满釉芒口　装烧：芒口覆烧
