# 金代定窑白釉印花花卉纹平底碟

- ID：DY-2009-231
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1④：144
- 完残程度：已复原
- 器类：碟
- 口沿：尖唇敞口，六花口
- 腹部：浅曲腹
- 底足：小平底
- 整体造型：敞口六花口浅腹小平底碟（C型），胎体轻薄，器内满印花
- 尺寸（厘米）：高 1.5，口径 9.9，足径 6.2
- 胎质：胎体较薄，胎质细腻　胎色：白胎泛灰
- 釉色：白釉泛灰，较光亮
- 施釉范围：内外满釉，芒口
- 釉面特征：内底及外底积釉处均可见黄色小气泡，施釉不均
- 纹饰：花口处对应内壁六道凸线分为六界格，每格内压印折枝花卉，内底为六瓣所成圆形，内印花卉纹
- 成型：　装饰技法：印花　施釉技法：　装烧：覆烧（芒口）
- 研究说明：细白碟C型，与北京先农坛金墓定窑花草纹刻花碟、吉林农安金代窖藏白釉印花碟形制与纹饰相同，年代属金代后期。
