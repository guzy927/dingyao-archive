# 金代定窑灰青釉花口碗

- ID：DY-2009-249
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：474
- 完残程度：仅存口部及腹部，残高3.9厘米
- 器类：碗
- 口沿：侈口，花口
- 腹部：上腹斜直，下腹圆曲
- 底足：
- 整体造型：侈口花口曲腹矮圈足碗（C型），花口处对应内壁凸线纹，内底压环
- 尺寸（厘米）：高 3.9，口径 ，足径 
- 胎质：坚致　胎色：白胎
- 釉色：灰青釉，光亮
- 施釉范围：内外满釉，芒口
- 釉面特征：内腹及器外下腹积釉处泛青，釉面较多褐点杂质，可见黑色斑点，有棕眼；外壁有较深刻痕
- 纹饰：花口处对应内壁凸线纹，内底压环
- 成型：　装饰技法：素面（花口凸线）　施釉技法：　装烧：芒口覆烧（支圈覆烧）
- 研究说明：定窑涧西区金代后期灰青釉花口碗标本。
