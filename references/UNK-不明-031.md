# 定窑白釉弦纹三足樽

- ID：UNK-不明-031
- 来源文献：定瓷雅集：故宫博物院珍藏及出土定窑瓷器荟萃 (故宫博物院)
- 时代：北宋　出土年份：不明
- 出土地点：传世品
- 出土单位：
- 完残程度：完整
- 器类：樽
- 口沿：直口，口沿无釉
- 腹部：筒形腹，外壁凸起三组共六道弦纹
- 底足：平底下承以三蹄形足
- 整体造型：直口、筒形腹、三蹄形足
- 尺寸（厘米）：高 10.2，口径 15.9，足径 足距14.4
- 胎质：　胎色：
- 釉色：白中闪黄
- 施釉范围：口沿无釉，里外施白釉
- 釉面特征：釉质滋润
- 纹饰：外壁凸起三组共六道弦纹
- 成型：　装饰技法：　施釉技法：　装烧：
- 研究说明：北宋早期定窑白瓷釉色常白中闪青，之后则白中微泛黄，呈象牙般柔和质感，这是由于以煤取代薪柴作为烧窑燃料所致。
