# 金代定窑白釉刻花花卉纹盘

- ID：DY-2009-223
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：182
- 完残程度：已复原
- 器类：盘
- 口沿：尖唇，侈口
- 腹部：腹部斜直略曲
- 底足：矮圈足，挖足到肩
- 整体造型：侈口直腹略曲矮圈足盘（G型）
- 尺寸（厘米）：高 3.1，口径 17.4，足径 5.5
- 胎质：细腻坚致　胎色：白胎
- 釉色：白釉泛青，光亮
- 施釉范围：满釉，芒口
- 釉面特征：器外近底处及底部有积釉，釉面较多褐点杂质，有棕眼；器外口沿下及底部有粘沙
- 纹饰：内腹刻圆，圆内刻花卉纹；外壁有刻痕
- 成型：　装饰技法：刻花　施釉技法：　装烧：覆烧（芒口）
- 研究说明：定窑涧西区金代后期侈口盘标本。
