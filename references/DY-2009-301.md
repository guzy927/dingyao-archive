# 金代定窑酱釉小碗

- ID：DY-2009-301
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1④：360
- 完残程度：仅存口部及腹部，残高3.6厘米
- 器类：碗
- 口沿：尖唇，直口
- 腹部：上腹直，下腹圆曲
- 底足：
- 整体造型：直口曲腹矮圈足小碗（H型）
- 尺寸（厘米）：高 3.6，口径 ，足径 
- 胎质：胎较薄，坚致　胎色：白胎
- 釉色：酱釉泛黄，光亮
- 施釉范围：内外满釉，芒口
- 釉面特征：釉面少量黑色斑点，有棕眼；器外口部有少量粘沙
- 纹饰：素面
- 成型：　装饰技法：素面　施釉技法：　装烧：芒口覆烧（支圈覆烧）
- 研究说明：定窑涧西区金代后期酱釉小碗标本。
- 溯源备注：细酱碗H型标本，无图版。
