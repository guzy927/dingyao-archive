# 金代定窑白釉刻花缠枝花卉纹花口盘

- ID：DY-2009-213
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：33
- 完残程度：已复原
- 器类：盘
- 口沿：尖唇，敞口微侈，花口
- 腹部：上腹微凹，斜直腹微曲，内底微凹
- 底足：圈足较矮，挖足到肩，外底有S形裂痕，底心微凸
- 整体造型：敞口花口直腹略曲矮圈足盘（A型）
- 尺寸（厘米）：高 3.1，口径 17.2，足径 5.6
- 胎质：细密坚致，内腹及器外口沿下可见凸起小气泡　胎色：白胎
- 釉色：白釉泛灰，较光亮
- 施釉范围：内外满釉，芒口
- 釉面特征：器外近底处积釉，釉面有少量黑色斑点，含有较多褐点杂质
- 纹饰：器内花口处对应六道凸线纹，内底压环，压环内刻缠枝花卉纹；器外口沿下一周较浅凹痕，外壁拉坯所成弦纹较明显，外底有刻痕
- 成型：拉坯成形　装饰技法：刻花　施釉技法：　装烧：覆烧（芒口）
- 研究说明：缠枝莲纹多刻于盘内腹，配以简单卷草纹，为涧西区金代后期定窑盘类常见装饰。
