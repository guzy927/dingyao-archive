# 金代定窑白釉圜底钵

- ID：DY-2009-234
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：432
- 完残程度：可复原
- 器类：钵
- 口沿：薄唇，直口
- 腹部：上腹微鼓，下腹圆曲，内底下凹
- 底足：圜底，器外底部微鼓
- 整体造型：直口曲腹圜底钵（C型）
- 尺寸（厘米）：高 4.9，口径 ，足径 
- 胎质：细腻坚致　胎色：白胎
- 釉色：白釉，光亮
- 施釉范围：满釉，芒口
- 釉面特征：器外近底处一周积釉，釉面较多黑点杂质，有棕眼；外腹有粘连带火刺器物碎片
- 纹饰：内底刻圆
- 成型：　装饰技法：刻花（刻圆）　施釉技法：　装烧：覆烧（芒口）
- 研究说明：定窑涧西区金代后期圜底钵标本。
