# 金代定窑酱釉碗

- ID：DY-2009-295
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT2H2：253
- 完残程度：仅存口部及上腹部，残高4.2厘米
- 器类：碗
- 口沿：尖唇，敞口微敛
- 腹部：斜曲腹
- 底足：
- 整体造型：敞口斜曲腹矮圈足碗（B型），圈足较A型稍大
- 尺寸（厘米）：高 4.2，口径 ，足径 
- 胎质：坚致　胎色：白胎
- 釉色：内施酱釉，半木光；外施酱釉，较光亮
- 施釉范围：内外满釉，芒口
- 釉面特征：釉面少量杂质，有棕眼；外壁有刻痕
- 纹饰：素面
- 成型：　装饰技法：素面　施釉技法：　装烧：芒口覆烧（支圈覆烧）
- 研究说明：定窑涧西区金代后期酱釉碗标本。
- 溯源备注：细酱碗B型标本，无图版。
