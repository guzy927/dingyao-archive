# 北宋定窑白瓷碗

- ID：UNK-1981-003
- 来源文献：河南地区隋代至明代纪年墓出土瓷器研究_高雪薇
- 时代：北宋景德三年（1006）　出土年份：1981
- 出土地点：河南巩县西南伊洛河南岸宋太宗元德李后陵（永熙陵祔葬后陵）
- 出土单位：宋太宗元德李后陵
- 完残程度：
- 器类：碗
- 口沿：敞口（Ea式）或撇口（I式）
- 腹部：深腹（Ea式）或浅腹（I式）
- 底足：圈足（Ea式）或高圈足（I式）
- 整体造型：Ea式：敞口，深腹，圈足；I式：撇口，浅腹，高圈足
- 尺寸（厘米）：高 ，口径 ，足径 
- 胎质：胎质细密坚实；胎薄而透明（原文）　胎色：
- 釉色：白中闪青（整体呈白或白中微闪青）
- 施釉范围：
- 釉面特征：釉面光亮照人，釉面光洁细腻
- 纹饰：刻划相重叠莲瓣纹；亦有牡丹纹（图3.1.2“李后陵出土定窑碗牡丹纹”）
- 成型：　装饰技法：刻划花（刻划、划花）　施釉技法：　装烧：覆烧（原文：景德3年李后陵出土的一批定窑展示了覆烧工艺）
- 研究说明：圈足内阴刻“官”字款（原文：不少器物的圈足内阴刻有“官”字款）。原文：釉色白中闪青，釉面光亮照人，胎薄而透明；纹饰多为划花，以飞凤纹最常见；李后陵出土定窑有内底划飞凤纹的盘，也有刻划相重叠莲瓣纹的碗。附表四载定窑白瓷碗26件。
- 溯源备注：附表四：李后陵·定窑白瓷碗26件（景德3年1006），资料来源《宋太宗元德李后陵发掘报告》。图2.1.1之12（Ea式碗，李后陵）、18（I型碗，李后陵）；图3.1.2题记“李后陵出土定窑碗牡丹纹”，但该图仅提取2张子图，对应文件名无法确定，故images留空。1981年为暴雨致陵墓坍塌并获准发掘之年，原文未明言发掘年份。
