# 金代定窑酱釉大盘

- ID：DY-2009-302
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1④：361
- 完残程度：可复原
- 器类：盘
- 口沿：圆唇敞口，器外口沿下一周凹痕
- 腹部：浅曲腹，上腹较圆曲，下腹斜直
- 底足：圈足较大，微外撇，挖足过肩，底心微凸
- 整体造型：圈足大盘（A型）
- 尺寸（厘米）：高 7.5，口径 ，足径 
- 胎质：细密坚致　胎色：白胎
- 釉色：内酱釉，有大片泛棕黄色，光泽暗淡；外酱釉，泛木光
- 施釉范围：施釉不均，多处露胎较明显
- 釉面特征：釉面较多杂质，有棕眼；外壁及圈足积釉；内外均有粘痕，器内口沿下粘连另一酱釉盘口沿
- 纹饰：素面
- 成型：　装饰技法：素面　施釉技法：　装烧：
- 研究说明：定窑涧西区金代后期酱釉大盘标本，口沿粘连另一盘口沿反映覆烧装烧状态。
- 溯源备注：细酱盘A型标本，无图版。
