# 唐代邢/定窑白釉提梁式鸡冠壶

- ID：YZ-不明-075
- 来源文献：江苏省出土的隋唐五代瓷器研究_武夏
- 时代：唐　出土年份：不明
- 出土地点：江苏省扬州市扬州城蜀冈下城址内文化宫遗址
- 出土单位：扬州城蜀冈下城址内遗址—文化宫遗址YWF1:134
- 完残程度：
- 器类：鸡冠壶
- 口沿：提梁式，提梁一侧有圆形管状流
- 腹部：壶下部饱满
- 底足：浅圈足
- 整体造型：壶上部呈扁形，中间有提梁带钮；壶身两侧及流下部有线纹凸棱，形如皮囊缝合线痕
- 尺寸（厘米）：高 22.6，口径 2.4（流嘴径），足径 10.3
- 胎质：胎较粗，施白色化妆土　胎色：黄白
- 釉色：牙白釉
- 施釉范围：外壁施釉不到底
- 釉面特征：光亮，有细开片
- 纹饰：提梁两侧模印三角状毡子纹，类似马背上的障泥巾络
- 成型：模制（内侧中段有横接痕）　装饰技法：模印　施釉技法：　装烧：
- 研究说明：原文4.2节：中晚唐邢窑、定窑器物相似度高，不易区分，将本组器物判定为邢/定窑产品。A组特征：胎质洁白细腻，釉色白中微泛灰或青，釉层较薄，除底足外施满釉，未发现支钉痕，底足有垫沙痕迹，器型规整，均为细白瓷。原文：鸡冠壶与河北省衡水市文物管理处藏邢窑白釉凤首盖贴花皮囊壶形制相同，仅仿制皮囊缝合线的形状曲线不一。
