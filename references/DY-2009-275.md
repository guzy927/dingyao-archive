# 金代定窑黑釉刻花萱草纹小碗

- ID：DY-2009-275
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：417
- 完残程度：已复原
- 器类：碗
- 口沿：尖唇较薄，敞口
- 腹部：上腹斜直，下腹圆曲
- 底足：小圈足较矮，挖足极浅，近底处有粘连痕
- 整体造型：敞口曲腹小圈足碗（C型），胎体轻薄，内壁满刻萱草纹
- 尺寸（厘米）：高 3.6，口径 9.4，足径 2.4
- 胎质：胎较轻薄，细腻，外壁凸起处有较大块白色斑点　胎色：白胎
- 釉色：黑釉泛棕褐色，较光亮
- 施釉范围：内外满釉，芒口
- 釉面特征：器外近底处及圈足积釉，釉面较多杂质，施釉不均
- 纹饰：内壁满刻萱草纹
- 成型：　装饰技法：刻花　施釉技法：　装烧：覆烧（芒口）
- 研究说明：细黑釉类器物中刻花装饰多用于器物内底，萱草纹为常见纹饰。
