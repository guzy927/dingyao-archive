# 金代定窑双色釉盘

- ID：DY-2009-324
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：507
- 完残程度：仅存口部及上腹部，残高尺寸原文缺失
- 器类：盘
- 口沿：尖唇，敞口
- 腹部：腹部斜直略曲
- 底足：
- 整体造型：敞口直腹略曲矮圈足盘（A型）
- 尺寸（厘米）：高 ，口径 ，足径 
- 胎质：较坚致，起层，可见小气泡　胎色：白胎
- 釉色：内白釉，较光亮；外酱釉泛青，较光亮
- 施釉范围：内外满釉，芒口
- 釉面特征：内壁釉面较多黑点杂质，有棕眼；外壁口沿处粘釉，釉面有较深刻划痕，可见少量灰色落砂
- 纹饰：素面
- 成型：　装饰技法：素面　施釉技法：　装烧：覆烧（芒口）
- 研究说明：定窑涧西区金代后期双色釉盘标本。
- 溯源备注：细瓷双色釉盘A型标本，无图版。残高原文缺失。
