# 定窑白釉刻划花石榴纹碗

- ID：UNK-不明-050
- 来源文献：定瓷雅集：故宫博物院珍藏及出土定窑瓷器荟萃 (故宫博物院)
- 时代：北宋　出土年份：不明
- 出土地点：传世品
- 出土单位：
- 完残程度：完整
- 器类：碗
- 口沿：口微撇，镶铜釦
- 腹部：深弧壁
- 底足：圈足
- 整体造型：口微撇、深弧壁、圈足
- 尺寸（厘米）：高 8.9，口径 18.6，足径 7.8
- 胎质：　胎色：
- 釉色：白中略泛牙黄
- 施釉范围：内外施白釉
- 釉面特征：局部垂流如泪痕
- 纹饰：碗内光素无纹；外刻缠枝石榴纹，一侧为花朵，一侧为绽开的榴实，缠绕的枝叶将花与榴实连为一体
- 成型：　装饰技法：刻划花　施釉技法：　装烧：
- 研究说明：石榴因多子而满足人们祈求多子多孙的愿望，被赋予吉祥寓意，大量用作工艺美术品的装饰题材。
