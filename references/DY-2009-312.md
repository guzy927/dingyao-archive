# 金代定窑粗酱釉碗

- ID：DY-2009-312
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：81
- 完残程度：已复原
- 器类：碗
- 口沿：圆唇，敞口
- 腹部：曲腹，内底涩圈较宽，内底心有一小平台，外壁一周较宽凹痕
- 底足：圈足较厚，足端斜削，圈足外侧有一周棱状凸起，挖足过肩
- 整体造型：敞口圆唇曲腹圈足碗，内底涩圈
- 尺寸（厘米）：高 5.6，口径 16.9，足径 6.9
- 胎质：粗而坚致，胎体拉坯痕较明显，含大量黑色杂质　胎色：黄砂胎
- 釉色：酱釉泛褐色，泛木光
- 施釉范围：内满釉，外施釉至上腹，下腹及圈足无釉
- 釉面特征：釉面可见开片，有积釉，有灰色落砂
- 纹饰：内底涩圈较宽
- 成型：拉坯成形　装饰技法：素面　施釉技法：　装烧：涩圈叠烧
- 研究说明：粗瓷酱釉碗内底涩圈，采用涩圈叠烧法烧造，属定窑粗瓷产品。
