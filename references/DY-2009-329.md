# 金代定窑粗瓷双色釉碗

- ID：DY-2009-329
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：98
- 完残程度：已复原
- 器类：碗
- 口沿：敞口，圆唇
- 腹部：腹部圆曲，内底涩圈稍宽，底心有较明显凹痕，外壁有两处明显凸起
- 底足：圈足较厚，挖足过肩，圈足及底部无釉
- 整体造型：敞口圆唇曲腹矮圈足碗（A型），内底涩圈
- 尺寸（厘米）：高 5.8，口径 16.2，足径 6.7
- 胎质：粗而坚致，含有较多杂质　胎色：灰褐胎
- 釉色：器内透明釉泛青色；器外两色釉，上透明釉泛青下酱釉，泛木光
- 施釉范围：圈足及底部无釉
- 釉面特征：内壁腹部有长条状开片，积釉处可见较多小气泡，釉面有少量褐色杂质，下腹有两道环形酱彩；器外釉面有较多杂质，釉色不均；器外口沿及底部有少量粘沙
- 纹饰：器内下腹有两道环形酱彩
- 成型：　装饰技法：酱彩　施釉技法：　装烧：涩圈叠烧
- 研究说明：粗瓷双色釉碗内底涩圈，采用涩圈叠烧法烧造，上透明釉下酱釉为双色釉组合。
