# 金代定窑双色釉碗

- ID：DY-2009-323
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：505
- 完残程度：可复原，残高3.6厘米
- 器类：碗
- 口沿：直口
- 腹部：深圆曲腹
- 底足：矮圈足，近底处及底部露胎呈红褐色，近底处有两条较宽粘痕露白胎
- 整体造型：直口曲腹圈足碗（D型）
- 尺寸（厘米）：高 3.6，口径 ，足径 
- 胎质：较细腻　胎色：白胎泛灰
- 釉色：器内白釉泛青，较光亮；外灰青釉，泛木光
- 施釉范围：内外满釉
- 釉面特征：内壁含有较多细小的褐色杂质，有一较大块褐色斑点，其下有较深凹痕；外壁下腹及圈足处有积釉，积釉处可见较多小气泡；近底处及底部露胎呈红褐色
- 纹饰：素面
- 成型：　装饰技法：素面　施釉技法：　装烧：
- 研究说明：定窑涧西区金代后期双色釉碗标本，内白釉外灰青釉。
- 溯源备注：细瓷双色釉碗D型标本，无图版。
