# 金代定窑酱釉盘

- ID：DY-2009-304
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1④：363
- 完残程度：已复原
- 器类：盘
- 口沿：薄唇稍宽，敞口
- 腹部：浅曲腹，内底微凸
- 底足：矮圈足，挖足不到肩，足端露胎
- 整体造型：敞口浅曲腹盘（B型），器外口沿下一周凹痕
- 尺寸（厘米）：高 3.6，口径 18.2，足径 7.2
- 胎质：细腻坚致　胎色：白胎泛灰
- 釉色：酱釉泛黑色，较光亮
- 施釉范围：内外均施满釉，芒口
- 釉面特征：圈足内外积釉，足端露胎，器外底心旋坯痕明显
- 纹饰：素面
- 成型：拉坯成形　装饰技法：素面　施釉技法：　装烧：覆烧（芒口）
- 研究说明：定窑涧西区金代后期酱釉盘标本。
