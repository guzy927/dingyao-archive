# 金代定窑白釉印花凤鸟牡丹纹折沿盘

- ID：DY-2009-220
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1④：378
- 完残程度：可复原
- 器类：盘
- 口沿：敞口，葵花型口，折沿
- 腹部：浅曲腹
- 底足：隐圈足，底不平
- 整体造型：敞口葵花型口折沿隐圈足盘（E型）
- 尺寸（厘米）：高 2.1，口径 ，足径 
- 胎质：细腻坚致　胎色：白胎泛灰
- 釉色：白釉泛青灰，较光亮
- 施釉范围：内外均施满釉，芒口
- 釉面特征：器外折沿下一周凹弦纹，内外有较多长条状开片，外腹积釉处可见较多小气泡，外壁及底有大片灰色落砂
- 纹饰：口部饰葵花瓣一周，折沿内饰几何纹，内壁印有间隔匀称的凸线纹，内底印有凤鸟牡丹纹
- 成型：　装饰技法：印花　施釉技法：　装烧：覆烧（芒口）
- 研究说明：凤穿花卉纹为金代定窑印花题材之一，折沿葵口盘内底印凤鸟牡丹纹较为少见。
