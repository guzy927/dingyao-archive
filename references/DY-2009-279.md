# 金代定窑黑釉小碗

- ID：DY-2009-279
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1⑤：407
- 完残程度：已复原
- 器类：碗
- 口沿：尖唇，侈口
- 腹部：上腹微收，下腹斜曲
- 底足：小圈足较矮，挖足较浅
- 整体造型：侈口斜曲腹圈足小碗（F型），腹部微圆曲
- 尺寸（厘米）：高 4.7，口径 12.1，足径 3.1
- 胎质：细腻坚致，胎体稍厚　胎色：白胎
- 釉色：黑釉泛棕色，较光亮
- 施釉范围：内外满釉，芒口
- 釉面特征：釉面较多杂质，圈足及底部积釉
- 纹饰：器外口沿下一周凹痕
- 成型：　装饰技法：素面　施釉技法：　装烧：覆烧（芒口）
- 研究说明：定窑涧西区金代后期黑釉小碗标本。
