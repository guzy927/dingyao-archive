# 唐末五代定窑精细白瓷碗

- ID：DY-2009-491
- 来源文献：高美京《定窑研究》2015（修订版）未设密码
- 时代：唐末五代　出土年份：2009
- 出土地点：河北省曲阳县定窑遗址北镇区
- 出土单位：09BZT5⑫:8
- 完残程度：失足
- 器类：碗
- 口沿：尖唇，花形敞口
- 腹部：斜腹近斗笠形
- 底足：小圈足，足端较窄，内外斜削
- 整体造型：精细白瓷碗Ca型Ⅰ式，敞口斜曲腹小碗
- 尺寸（厘米）：高 3.1，口径 15.6，足径 
- 胎质：胎体极薄，胎质极细密（胎体透光）　胎色：白胎很薄
- 釉色：白釉闪青
- 施釉范围：施釉到下腹，施釉到底
- 釉面特征：釉面光润
- 纹饰：素面
- 成型：轮制　装饰技法：　施釉技法：施满釉裹足刮釉　装烧：正烧
- 研究说明：精细白瓷碗Ca型Ⅰ式。胎体透光。
