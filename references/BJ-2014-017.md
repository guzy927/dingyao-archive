# 金代定窑白釉印花双鱼盘

- ID：BJ-2014-017
- 来源文献：北京市丰台区万泉寺金中都城内遗址G5考古发掘简报_卜彦博__
- 时代：金代后期　出土年份：2014
- 出土地点：北京市丰台区万泉寺金中都城内遗址
- 出土单位：G5
- 完残程度：
- 器类：盘
- 口沿：敞口，尖圆唇
- 腹部：弧腹
- 底足：圈足
- 整体造型：敞口，弧腹，圈足
- 尺寸（厘米）：高 4.6，口径 20.6，足径 8
- 胎质：　胎色：
- 釉色：白釉（细白釉）
- 施釉范围：内外满釉（据结语）
- 釉面特征：
- 纹饰：内底印双鱼纹，周壁印荷花纹
- 成型：　装饰技法：印花；足心刻划　施釉技法：　装烧：覆烧（据结语）
- 研究说明：足心刻划“尚食局”三字款，为上釉后、烧制前所刻。“尚食局”款印花双鱼盘与河北崇礼太子城金代后期皇帝行宫出土“尚食局”盘类似，普遍认为是金代后期产品；“尚食局”款均竖刻于圈足内中部或左右侧，装烧方法为覆烧。
