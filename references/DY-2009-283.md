# 金代定窑黑釉盘

- ID：DY-2009-283
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：150
- 完残程度：已复原
- 器类：盘
- 口沿：宽唇，敞口
- 腹部：浅曲腹
- 底足：矮圈足，挖足过肩
- 整体造型：敞口浅曲腹盘（C型），薄唇较宽，器外口沿下一周凹痕
- 尺寸（厘米）：高 3.2，口径 21.2，足径 8.6
- 胎质：细腻坚致　胎色：白胎
- 釉色：黑釉泛酱色，较光亮
- 施釉范围：满釉，芒口
- 釉面特征：圈足处积釉，釉面少量杂质，有棕眼
- 纹饰：器外口沿下一周凹痕
- 成型：　装饰技法：素面　施釉技法：　装烧：覆烧（芒口）
- 研究说明：定窑涧西区金代后期黑釉盘标本。
