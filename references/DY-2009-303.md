# 金代定窑酱釉盘

- ID：DY-2009-303
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT2④：353
- 完残程度：已复原
- 器类：盘
- 口沿：尖唇，敞口微敛
- 腹部：上腹微曲，下腹斜收，内底微凹
- 底足：圈足较矮，挖足到肩
- 整体造型：敞口浅曲腹盘（B型）
- 尺寸（厘米）：高 3.1，口径 17.8，足径 6.3
- 胎质：细腻坚致　胎色：白胎泛灰
- 釉色：酱釉泛黄，较光亮
- 施釉范围：内外满釉，芒口
- 釉面特征：器外积釉处可见小气泡，釉面有较多黑色杂质
- 纹饰：素面；外壁有较深凹痕，拉坯痕显著
- 成型：拉坯成形　装饰技法：素面　施釉技法：　装烧：覆烧（芒口）
- 研究说明：定窑涧西区金代后期酱釉盘标本。
