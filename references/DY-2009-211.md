# 金代定窑白釉小碗

- ID：DY-2009-211
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：237
- 完残程度：已复原
- 器类：碗
- 口沿：尖唇，敞口
- 腹部：上腹斜直，下腹曲收
- 底足：圈足较矮，外底有裂痕底心微凸，挖足较浅
- 整体造型：直口曲腹矮圈足小碗（K型）
- 尺寸（厘米）：高 4.2，口径 10.6，足径 3.1
- 胎质：较细腻　胎色：白胎
- 釉色：白釉泛灰，较光亮
- 施釉范围：内外满釉，芒口
- 釉面特征：外腹积釉处可见较多小气泡，釉面较多褐点杂质及少量黑色斑点，可见少量棕眼
- 纹饰：素面
- 成型：　装饰技法：素面　施釉技法：　装烧：覆烧（芒口）
- 研究说明：定窑涧西区金代后期直口小碗标本，属K型素面者。
