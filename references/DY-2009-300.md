# 金代定窑酱釉刮烧碗

- ID：DY-2009-300
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT2③：412
- 完残程度：仅存口部及上腹部，残高2.9厘米
- 器类：碗
- 口沿：薄唇，侈口
- 腹部：腹部斜曲
- 底足：
- 整体造型：刮烧碗（G型），器内外有较宽刮釉带
- 尺寸（厘米）：高 2.9，口径 ，足径 
- 胎质：坚致　胎色：白胎
- 釉色：内酱釉泛黄，较光亮；外酱釉
- 施釉范围：内外满釉，芒口
- 釉面特征：内壁有黄色落砂，口沿处有点状酱釉，口沿下一周粘釉，釉面有黄色斑点，有棕眼
- 纹饰：器内外有较宽刮釉带
- 成型：　装饰技法：素面　施釉技法：刮釉（器内外较宽刮釉带）　装烧：覆烧（芒口）
- 研究说明：酱釉刮烧碗，为支圈覆烧配套产品。
- 溯源备注：细酱碗G型（刮烧碗）标本，无图版。
