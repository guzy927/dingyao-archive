# 北宋定窑白釉杯

- ID：DZ-不明-075
- 来源文献：宋辽金时期佛塔出土瓷器研究_隋璐
- 时代：北宋（太平兴国二年，977年）　出土年份：不明
- 出土地点：河北定县静志寺塔
- 出土单位：地宫
- 完残程度：
- 器类：杯
- 口沿：短直口
- 腹部：短颈，圆曲腹
- 底足：圜底内凹
- 整体造型：短直口，短颈，圆曲腹，圜底内凹
- 尺寸（厘米）：高 ，口径 ，足径 
- 胎质：胎质细白，多为薄胎　胎色：白
- 釉色：白釉，略闪黄、闪青或泛灰
- 施釉范围：多数施满釉，仅足底无釉
- 釉面特征：釉质匀净，有垂釉痕
- 纹饰：腹满印柳编纹
- 成型：　装饰技法：模印　施釉技法：不施化妆土　装烧：
- 研究说明：定州两塔地宫白瓷为北宋早期定窑代表性产品，两塔白瓷有些器底带刻划'官'款。
- 溯源备注：表一·静志寺塔白釉杯4件合并；原文作'杯 静志寺塔地宫出土'
