# 金代定窑灰青釉刻花花式盘

- ID：DY-2009-253
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：482
- 完残程度：可复原
- 器类：盘
- 口沿：敞口，花口
- 腹部：深花瓣形圆曲腹
- 底足：矮圈足，挖足过肩
- 整体造型：敞口深花瓣形浅腹矮圈足花式盘（B型），内底刻花装饰
- 尺寸（厘米）：高 3.2，口径 ，足径 
- 胎质：坚致　胎色：白胎
- 釉色：灰青釉，光亮
- 施釉范围：满釉，芒口
- 釉面特征：圈足内外积釉，釉面有黑色斑点，可见黑色落砂
- 纹饰：外腹壁对应花口处压花瓣形凹弦纹，内壁对应处凸起使腹部呈花瓣形，内底刻花装饰
- 成型：　装饰技法：刻花　施釉技法：　装烧：覆烧（芒口）
- 研究说明：定窑涧西区金代后期灰青釉花式盘标本。
