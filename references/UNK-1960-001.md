# 定窑白釉弦纹三足樽

- ID：UNK-1960-001
- 来源文献：定瓷雅集：故宫博物院珍藏及出土定窑瓷器荟萃 (故宫博物院)
- 时代：北宋　出土年份：1960
- 出土地点：湖南省长沙市杨家湾东风钢厂一号墓
- 出土单位：杨家湾东风钢厂一号墓
- 完残程度：完整
- 器类：樽
- 口沿：直口，口沿露胎
- 腹部：筒形腹
- 底足：腹下承以三个蹄形足（最下一道弦纹起定位蹄形足的作用）
- 整体造型：直口、筒形腹、三蹄形足
- 尺寸（厘米）：高 6.7，口径 10.8，足径 10.4
- 胎质：　胎色：
- 釉色：白中泛黄
- 施釉范围：除口沿露胎外，通体施白釉
- 釉面特征：
- 纹饰：外壁饰六道规整精致的凸弦纹
- 成型：　装饰技法：　施釉技法：　装烧：
- 研究说明：造型模仿汉代青铜酒樽，宋代其功用则可能是焚香；造型与北宋汝窑三足樽相似，制作十分精致，堪称定窑瓷器中的珍品。
