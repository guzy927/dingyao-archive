# 金代定窑黑釉盘

- ID：DY-2009-282
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1④：355
- 完残程度：已复原
- 器类：盘
- 口沿：尖唇，敞口
- 腹部：浅曲腹，内底微凹
- 底足：圈足较矮，器外底心微凸，挖足过肩
- 整体造型：敞口浅曲腹盘（C型）
- 尺寸（厘米）：高 3.2，口径 16.7，足径 6.6
- 胎质：细腻坚致　胎色：白胎
- 釉色：内壁黑釉较光亮，施釉均匀；外壁黑釉泛酱色，较光亮
- 施釉范围：满釉，芒口
- 釉面特征：器外近底处及底部积釉，釉面少量杂质，有棕眼，底部施釉不均
- 纹饰：素面
- 成型：　装饰技法：素面　施釉技法：　装烧：覆烧（芒口）
- 研究说明：定窑涧西区金代后期黑釉盘标本。
