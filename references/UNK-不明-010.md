# 定窑白釉印花单摩羯花卉纹“尚食局”款碗

- ID：UNK-不明-010
- 来源文献：论定窑“尚食局”款瓷器的分期问题_黄信
- 时代：金代后期　出土年份：不明
- 出土地点：太子城遗址（河北张家口市崇礼区，金代皇家行宫）
- 出土单位：17CTT1610∶3
- 完残程度：可复原
- 器类：碗
- 口沿：方唇，敞口，芒口
- 腹部：深曲腹
- 底足：高圈足微外撇；圈足内中部竖刻“尚食局”款
- 整体造型：方唇，敞口，深曲腹，高圈足微外撇
- 尺寸（厘米）：高 8.8，口径 18.1，足径 7.5
- 胎质：细腻坚致　胎色：白
- 釉色：白
- 施釉范围：内外及圈足满釉，芒口
- 釉面特征：白釉莹润
- 纹饰：内底印单摩羯花卉纹，内腹印花卉纹，内口沿下印如意形云纹带，内底、腹印花区用双凸弦纹相隔
- 成型：　装饰技法：印花　施釉技法：　装烧：覆烧
- 研究说明：太子城遗址出土的金代后期A型“尚食局”款碗，圈足内中部竖刻“尚食局”款，经北京大学科技考古实验室成分测定确为河北曲阳定窑产品。
