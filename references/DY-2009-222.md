# 金代定窑白釉刻花花卉纹盘

- ID：DY-2009-222
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：124
- 完残程度：已复原
- 器类：盘
- 口沿：尖唇，侈口
- 腹部：腹部斜直略曲，内底下凹，底心微凸
- 底足：矮圈足，挖足到肩
- 整体造型：侈口直腹略曲矮圈足盘（G型）
- 尺寸（厘米）：高 2.9，口径 17.5，足径 5.4
- 胎质：较坚致，可见少量裂痕　胎色：白胎
- 釉色：白釉泛青，较光亮
- 施釉范围：满釉，芒口
- 釉面特征：器外近底处及底部有积釉，釉面较多褐点杂质，外壁有褐色落砂，有棕眼
- 纹饰：内底刻圆，圆内刻花卉纹
- 成型：　装饰技法：刻花　施釉技法：　装烧：覆烧（芒口）
- 研究说明：细白盘G型，与北京先农坛金墓所出定窑白釉盘造型相同，为金代后期断代依据之一。
