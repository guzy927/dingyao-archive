# 金代定窑白釉印花缠枝花卉纹盘

- ID：DY-2009-217
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1④：373
- 完残程度：已复原
- 器类：盘
- 口沿：尖唇，敞口
- 腹部：曲腹
- 底足：矮圈足，挖足到肩
- 整体造型：敞口曲腹矮圈足盘（C型），内壁满印花
- 尺寸（厘米）：高 4.2，口径 20.6，足径 8.4
- 胎质：较坚致，有气泡可见裂痕　胎色：白胎
- 釉色：白釉微泛青，较光亮
- 施釉范围：满釉，芒口
- 釉面特征：器外近底处积釉，釉面较多褐点杂质
- 纹饰：器内口沿下两条凸线内印一周云纹，内壁满印缠枝花卉纹，内底印鱼纹
- 成型：　装饰技法：印花　施釉技法：　装烧：覆烧（芒口）
- 研究说明：满印花曲腹盘为金代后期定窑印花装饰鼎盛期的典型产品。
