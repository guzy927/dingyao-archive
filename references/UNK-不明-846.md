# 晚唐五代定窑白釉唇口玉环足碗（桂阳山城出土，可复原）

- ID：UNK-不明-846
- 来源文献：高美京《定窑研究》2015（修订版）未设密码
- 时代：晚唐五代（该遗址出土定窑瓷与中白瓷相似）　出土年份：不明
- 出土地点：韩国仁川广域市桂阳区桂阳山城
- 出土单位：Tr2（探沟2）
- 完残程度：可复原器
- 器类：碗
- 口沿：唇口，肿唇饱满，断面可见圆孔
- 腹部：斜腹，到接足处削一道
- 底足：玉环足，挖足较浅，足端部修足痕明显，足部无釉
- 整体造型：内圜底唇口玉环足碗
- 尺寸（厘米）：高 4.4，口径 14，足径 5.4
- 胎质：致密　胎色：灰白胎
- 釉色：白釉
- 施釉范围：施釉到下外底
- 釉面特征：白釉呈灰褐色，釉溶解不善可见小黑斑
- 纹饰：
- 成型：　装饰技法：　施釉技法：　装烧：
