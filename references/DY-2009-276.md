# 金代定窑黑釉兔毫纹碗

- ID：DY-2009-276
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1④：358
- 完残程度：已复原
- 器类：碗
- 口沿：厚圆唇，敞口
- 腹部：斜深曲腹，器内底心下凹
- 底足：小圈足较矮，挖足极浅
- 整体造型：敞口深斜曲腹小圈足厚胎碗（D型）
- 尺寸（厘米）：高 4.5，口径 8.8，足径 2.8
- 胎质：坚致，厚胎　胎色：白胎泛灰
- 釉色：黑釉较光亮
- 施釉范围：内外满釉，芒口
- 釉面特征：内外口沿处有环带状积釉，釉层较厚，有较多棕眼，圈足处釉层较薄使黑釉泛黄色；器内口沿处有粘釉痕
- 纹饰：内壁有兔毫纹
- 成型：　装饰技法：窑变（兔毫纹）　施釉技法：　装烧：覆烧（芒口）
- 研究说明：内壁带兔毫纹的黑釉碗在涧西区定窑黑釉瓷中较有特色。
