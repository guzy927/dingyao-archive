# 金代定窑白釉隐圈足钵

- ID：DY-2009-237
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：438
- 完残程度：可复原
- 器类：钵
- 口沿：宽扁唇，直口
- 腹部：上腹斜曲，下腹圆曲，近底处折收
- 底足：隐圈足，挖足过肩
- 整体造型：直口曲腹隐圈足钵（E型），内底刻圆
- 尺寸（厘米）：高 4.1，口径 ，足径 
- 胎质：细腻坚致　胎色：白胎
- 釉色：白釉，光亮
- 施釉范围：内外满釉，芒口
- 釉面特征：内壁少量积釉，外壁折腹及圈足处环状积釉，釉面较多黑点杂质，有棕眼，近底处灰色落砂
- 纹饰：内底刻圆
- 成型：　装饰技法：刻花（刻圆）　施釉技法：　装烧：覆烧（芒口）
- 研究说明：定窑涧西区金代后期隐圈足钵标本。
