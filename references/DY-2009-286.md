# 金代定窑黑釉盘

- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：413
- 完残程度：可复原
- 器类：盘
- 口沿：尖唇，侈口
- 腹部：浅曲腹
- 底足：圈足较矮，挖足过肩

- 釉面特征：圈足内外积釉，釉面有少量杂质
- 纹饰：器外口沿下一周凹痕
- 成型：　装饰技法：素面　施釉技法：　装烧：芒口覆烧（支圈覆烧）
