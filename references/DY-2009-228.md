# 金代定窑白釉刻花折枝莲纹碟

- ID：DY-2009-228
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：168
- 完残程度：已复原
- 器类：碟
- 口沿：尖唇敞口
- 腹部：浅曲腹，内底微凹
- 底足：圈足较矮，底部有粘连支圈痕
- 整体造型：敞口浅腹矮圈足碟（A型），上腹较内收，下腹较圆曲
- 尺寸（厘米）：高 2.5，口径 12.3，足径 6.9
- 胎质：胎质细腻，起层，可见气孔裂痕　胎色：白胎泛灰
- 釉色：白釉泛青黄，泛木光
- 施釉范围：内外均施满釉，芒口
- 釉面特征：有少量黑色杂质及大量棕眼
- 纹饰：内底刻圆，圆内刻一折枝莲纹
- 成型：拉坯成形（器外拉坯痕显著）　装饰技法：刻花　施釉技法：　装烧：覆烧（芒口，底部有粘连支圈痕）
- 研究说明：细白碟A型，与辽宁朝阳金代壁画墓马令夫妇合葬墓（金大定二十四年，1184年）所出刻花萱草纹盘形制相同，为金代后期断代依据之一。
