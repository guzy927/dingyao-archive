# 金代定窑酱釉折沿盆

- ID：DY-2009-315
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：186
- 完残程度：已复原
- 器类：盆
- 口沿：圆唇，敞口，折沿
- 腹部：腹部斜直
- 底足：平底
- 整体造型：敞口折沿平底盆
- 尺寸（厘米）：高 13.8，口径 44.1，足径 21.7
- 胎质：粗而坚致，含有较多杂质　胎色：黄砂胎
- 釉色：内酱釉泛黑色，较光亮；外酱釉泛褐色，半木光
- 施釉范围：内外满釉，器内折沿处无釉
- 釉面特征：内壁釉面较多棕眼；外壁釉面粗糙，有较多火刺，可见较多灰色落砂，器内折沿处可见刮釉痕
- 纹饰：素面
- 成型：　装饰技法：素面　施釉技法：刮釉（器内折沿处刮釉痕）　装烧：
- 研究说明：粗酱釉折沿平底盆为定窑酱釉粗瓷产品。
- 溯源备注：粗酱盆标本，无图版。
