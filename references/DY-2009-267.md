# 金代定窑化妆白瓷铁锈花碗

- ID：DY-2009-267
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT2③：443
- 完残程度：仅存口沿及上腹部，残高3.2厘米
- 器类：碗
- 口沿：敞口微侈，圆唇
- 腹部：曲腹
- 底足：
- 整体造型：敞口圆唇曲腹圈足碗（A型）
- 尺寸（厘米）：高 3.2，口径 ，足径 
- 胎质：粗而坚致　胎色：灰胎
- 釉色：内化妆土外施透明釉泛灰青色；外施化妆土不及底
- 施釉范围：内满釉，外施化妆土不及底
- 釉面特征：较光亮，器外口沿下积釉，可见棕眼，釉面少量褐点杂质
- 纹饰：内壁有铁锈花
- 成型：　装饰技法：铁锈花　施釉技法：化妆土（器内及器外口沿下施化妆土）　装烧：
- 研究说明：化妆白瓷为定窑烧造最早的一类产品，金代灰青釉瓷逐渐取代化妆白瓷致其比重下降，属平民日用瓷器。
- 溯源备注：化妆白瓷碗A型标本，无图版。
