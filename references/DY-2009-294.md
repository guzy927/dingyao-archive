# 金代定窑酱釉印花六格花卉纹碗

- ID：DY-2009-294
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：179
- 完残程度：已复原
- 器类：碗
- 口沿：尖唇，敞口微侈
- 腹部：腹部斜直略曲，内底下凹，内圜底
- 底足：矮圈足，挖足过肩
- 整体造型：敞口斜直腹略曲矮圈足碗（A型），内壁满印花
- 尺寸（厘米）：高 4.8，口径 16.8，足径 5.1
- 胎质：胎体较薄，胎质细密坚致　胎色：白胎
- 釉色：酱釉较光亮
- 施釉范围：内外满釉，芒口
- 釉面特征：内壁施釉均匀，外壁近底处及底部施釉不均而露胎，釉面含有少量杂质
- 纹饰：内壁满印花，口沿处一周饰卷云纹，内壁印六道凸线将内壁分为六格，格内饰不同花卉纹，内底压环，压环内印花装饰
- 成型：　装饰技法：印花　施釉技法：　装烧：覆烧（芒口）
- 研究说明：薄胎酱釉印花碗为金代定窑装烧工艺成熟后的典型产品。
