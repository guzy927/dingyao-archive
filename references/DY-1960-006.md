# 定窑芒口盘

- ID：DY-1960-006
- 来源文献：论磁州窑与定窑的联系和相互影响_秦大树
- 时代：五代（原报道地层断代；原文认为该断代存在问题）　出土年份：1960
- 出土地点：河北曲阳涧磁村定窑遗址（洞磁村遗址）
- 出土单位：1960年发掘所报道之五代地层
- 完残程度：
- 器类：盘
- 口沿：口部露胎（芒口）
- 腹部：
- 底足：底满釉
- 整体造型：
- 尺寸（厘米）：高 ，口径 ，足径 
- 胎质：　胎色：
- 釉色：
- 施釉范围：口部露胎（无釉），底满釉
- 釉面特征：
- 纹饰：
- 成型：　装饰技法：　施釉技法：　装烧：覆烧（原报道据此认为定窑五代起采用覆烧）
- 研究说明：1960年发掘洞磁村遗址时报道在五代地层中发现口部露胎、底满釉器物，据此认为定窑从五代时起采用覆烧方法；原文指出该地层的划分和断代存在问题：所报道的芒口盘从器形上看与河北平山嘉祐年间（1056－1063年）以后墓中出土的一件盘相同，该墓时代应在哲宗朝以后（1086年以后）。
