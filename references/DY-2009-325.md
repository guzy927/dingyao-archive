# 金代定窑双色釉刻花萱草纹盘

- ID：DY-2009-325
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：512
- 完残程度：可复原
- 器类：盘
- 口沿：尖唇，侈口
- 腹部：直腹略曲
- 底足：圈足较矮
- 整体造型：侈口直腹略曲矮圈足盘（B型），腹部刻圆内刻萱草纹
- 尺寸（厘米）：高 3.2，口径 ，足径 5.6
- 胎质：胎质细密坚致，起层，内壁可见较多气泡　胎色：灰白胎
- 釉色：内白外酱：白釉泛青灰，较光亮；外酱釉，光泽暗淡
- 施釉范围：内外满釉
- 釉面特征：白釉面较多黑色杂质；外酱釉含褐色杂质，釉色不均；外壁下腹部粘有三处白色器物残块
- 纹饰：腹部刻圆，圆内刻萱草纹
- 成型：　装饰技法：刻花　施釉技法：　装烧：
- 研究说明：定窑涧西区金代后期双色釉盘标本，内白外酱釉色组合。
