# 北宋中期定窑白釉刻花双系壶

- ID：UNK-1973-001
- 来源文献：中国陶瓷 定窑 (中国陶瓷编辑委员会编)
- 时代：北宋中期　出土年份：1973
- 出土地点：河北省定县东沿里村
- 出土单位：
- 完残程度：
- 器类：壶
- 口沿：广口，口颈相连
- 腹部：壶身刻两组牡丹
- 底足：
- 整体造型：龙形流，束带形曲柄，肩部有双系，系外各立一片

- 胎质：　胎色：
- 釉色：白釉
- 施釉范围：
- 釉面特征：
- 纹饰：壶身刻两组牡丹，纹饰轮廓线刻划有力
- 成型：　装饰技法：刻花　施釉技法：　装烧：
- 研究说明：1973年8月出土于河北定县东沿里村；龙形流、束带形曲柄都保留了早期的形式；系外各立一片，这种制作在南方青瓷中比较常见
