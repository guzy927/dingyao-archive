# 北宋前期定窑白釉划花双蝶纹墨书款洗

- ID：UNK-1969-005
- 来源文献：中国陶瓷 定窑 (中国陶瓷编辑委员会编)
- 时代：北宋前期　出土年份：1969
- 出土地点：河北省定县
- 出土单位：静志寺塔基（5号塔基）
- 完残程度：
- 器类：洗（盘）
- 口沿：花口五出
- 腹部：
- 底足：平底
- 整体造型：浅式
- 尺寸（厘米）：高 ，口径 ，足径 
- 胎质：　胎色：
- 釉色：白釉
- 施釉范围：
- 釉面特征：
- 纹饰：里心划细线条双蝶纹
- 成型：　装饰技法：划花　施釉技法：　装烧：
- 研究说明：纹饰题材内容、风格与浙江余姚上林湖越窑完全相同，明显受越窑影响；底墨书“太平兴国二年五月廿二日施主男弟子吴成训钱叁拾足陌供养舍利”二十八字；另一件同式洗底部墨书三十一字“太平兴国二年五月廿二日施主男弟子吴成训更施钱叁拾文足陌供养舍利”，字铭大体相同；正文称静志寺塔出土五出口平底盘两件，盘里心划对碟纹，与五代末宋初越窑异曲同工；两件带铭文器物解决了塔中出土瓷器的烧制时间，揭示了北宋早期定窑白瓷的面目
