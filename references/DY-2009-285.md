# 金代定窑黑釉盘

- ID：DY-2009-285
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：412
- 完残程度：可复原
- 器类：盘
- 口沿：薄唇，侈口
- 腹部：腹部斜直略曲
- 底足：圈足较矮，挖足极浅，底部有少量粘沙
- 整体造型：侈口斜直腹略曲矮圈足盘（E型）
- 尺寸（厘米）：高 4.1，口径 ，足径 
- 胎质：细腻坚致　胎色：白胎
- 釉色：黑釉泛酱色，较光亮
- 施釉范围：内外满釉，芒口
- 釉面特征：圈足内外积釉，釉面有少量杂质，有棕眼
- 纹饰：素面
- 成型：　装饰技法：素面　施釉技法：　装烧：芒口覆烧（支圈覆烧）
