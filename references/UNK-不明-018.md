# 定窑白釉刻「官」款罐

- ID：UNK-不明-018
- 来源文献：定瓷雅集：故宫博物院珍藏及出土定窑瓷器荟萃 (故宫博物院)
- 时代：唐晚期　出土年份：不明
- 出土地点：湖南长沙唐代墓葬
- 出土单位：长沙唐代墓葬
- 完残程度：完整
- 器类：罐
- 口沿：直口，短颈，涩口
- 腹部：溜肩，腹下渐收；腹下部有一道凹弦纹
- 底足：平底，底部露胎
- 整体造型：直口、短颈、溜肩、腹下渐收、平底
- 尺寸（厘米）：高 9.9，口径 5.2，足径 5.9
- 胎质：　胎色：
- 釉色：白
- 施釉范围：通体内外施白釉，底部露胎
- 釉面特征：釉质洁白莹润
- 纹饰：腹部离底0.6厘米处一道凹弦纹；底部刻「官」字款，字体不甚工整
- 成型：　装饰技法：刻款　施釉技法：以右手抓取器底施釉（凹弦纹周边可见五个手指抓痕）　装烧：
- 研究说明：底部露胎处刻「官」字款；罐腹下部凹弦纹周边可见五个用手指抓取罐底而形成的无釉痕迹，可知陶工用右手抓取器底施釉。近几十年来长沙地区发现数件刻「官」款的定窑白瓷，均出自墓主身份较高的墓葬；晚唐五代时期湖南曾向中原大量提供粮食茶叶，这些「官」款白瓷可能与朝廷赏赐湖南地方节度使有关。
