# 唐末五代定窑精细白瓷碗

- ID：DY-2009-480
- 来源文献：高美京《定窑研究》2015（修订版）未设密码
- 时代：唐末五代　出土年份：2009
- 出土地点：河北省曲阳县定窑遗址北镇区
- 出土单位：09BZT5⑦:6
- 完残程度：可复原器
- 器类：碗
- 口沿：尖圆唇，六花口，花口下对应凹棱，口部微外折
- 腹部：深腹，斜直壁至下腹圆曲内收
- 底足：大圈足，足墙斜直，高圈足外撇，挖足过肩，足径较大
- 整体造型：精细白瓷碗A型Ⅰ式，侈口斜曲腹高圈足大碗
- 尺寸（厘米）：高 8.8，口径 22，足径 9.2
- 胎质：胎体极薄，胎质极细密　胎色：白胎很薄
- 釉色：白釉闪青
- 施釉范围：施满釉裹足刮釉，足心满釉，足端刮釉
- 釉面特征：釉面光润
- 纹饰：素面（六花口，花口下对应凹棱；外壁浅凹线纹）
- 成型：轮制（外壁可见均匀修坯痕）　装饰技法：　施釉技法：施满釉裹足刮釉　装烧：正烧
- 研究说明：精细白瓷碗A型Ⅰ式。常见足底粘砂，足墙外存一刻痕。
