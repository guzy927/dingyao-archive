# 北宋定窑白瓷盘

- ID：UNK-1981-002
- 来源文献：河南地区隋代至明代纪年墓出土瓷器研究_高雪薇
- 时代：北宋景德三年（1006）　出土年份：1981
- 出土地点：河南巩县西南伊洛河南岸宋太宗元德李后陵（永熙陵祔葬后陵）
- 出土单位：宋太宗元德李后陵
- 完残程度：
- 器类：盘
- 口沿：敞口（Ba式、Bb式）
- 腹部：曲腹（Ba式）或斜腹内收（Bb式）
- 底足：圈足
- 整体造型：敞口，浅腹，圈足；分Ba式（敞口曲腹）与Bb式（敞口斜腹内收）
- 尺寸（厘米）：高 ，口径 ，足径 
- 胎质：胎质细密坚实　胎色：
- 釉色：乳白（整体呈白或白中微闪青）
- 施釉范围：仅口沿施釉至圈足根部，圈足根部露胎（原文）
- 釉面特征：釉面光洁细腻
- 纹饰：内底划花飞凤纹（纹饰多为划花，以飞凤纹最常见）
- 成型：　装饰技法：划花　施釉技法：　装烧：覆烧（原文：景德3年李后陵出土的一批定窑展示了覆烧工艺）
- 研究说明：圈足内阴刻“官”字款（原文：不少器物的圈足内阴刻有“官”字款）。原文：李后陵出土瓷器共计82件，可复原45件，其中3件越窑青瓷，其余为定窑白瓷，器形有盘和碗两种；釉色呈白或白中微闪青色，釉面光洁细腻，胎质细密坚实，纹饰多为划花，以飞凤纹最常见。附表四载定窑白瓷盘11件。
