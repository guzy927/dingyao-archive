# 金代定窑化妆白瓷碗

- ID：DY-2009-268
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1④：391
- 完残程度：仅存口部及腹部，残高4.5厘米
- 器类：碗
- 口沿：厚唇，唇下一周下凹
- 腹部：腹斜直略曲，内底有涩圈
- 底足：
- 整体造型：敞口厚唇斜直腹略曲圈足碗（B型），内底涩圈
- 尺寸（厘米）：高 4.5，口径 ，足径 
- 胎质：粗而坚致，有黑色杂质　胎色：灰胎
- 釉色：内化妆土外施透明釉泛灰青色；外施化妆土不及底，透明釉泛灰青
- 施釉范围：内满釉，外施化妆土不及底
- 釉面特征：较光亮，外腹积釉处泛青，釉面较多黑点杂质，有棕眼
- 纹饰：素面（内底涩圈）
- 成型：　装饰技法：素面　施釉技法：化妆土（器内及器外口沿下施化妆土）　装烧：涩圈叠烧
- 研究说明：化妆白瓷碗内底常见涩圈，采用涩圈叠烧法烧造。
- 溯源备注：化妆白瓷碗B型标本，无图版。
