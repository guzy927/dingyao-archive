# 金代定窑白釉刻花斗笠盏（T54④下土墙东沟：6）

- ID：UNK-2000-014
- 来源文献：2000年黄骅市海丰镇遗址出土金代瓷器初探_潘晓暾
- 时代：金代　出土年份：2000
- 出土地点：河北省黄骅市海丰镇遗址
- 出土单位：T54④下土墙东沟：6
- 完残程度：
- 器类：盏
- 口沿：大敞口，尖圆唇
- 腹部：斜直腹稍弧
- 底足：窄圈足较矮
- 整体造型：斗笠盏
- 尺寸（厘米）：高 ，口径 ，足径 
- 胎质：胎质洁白细腻，较坚硬；薄胎细腻，不施化妆土　胎色：洁白
- 釉色：白釉（白中闪青、黄）
- 施釉范围：满釉，芒口
- 釉面特征：釉层较薄，有垂釉现象，积釉处见细小气泡，釉面光亮；釉下可见轮修形成的竹丝刷痕
- 纹饰：刻花（同类斗笠盏刻花图案有萱草纹、蟹爪菊瓣纹等）
- 成型：轮制（釉下可见竹丝刷痕）　装饰技法：刻花　施釉技法：　装烧：覆烧（芒口）
- 研究说明：属精细白瓷甲组遗存；论文3.1.2节云其与定窑遗址采集的斗笠盏923如出一辙，是定窑瓷器非常有代表性的器型；《韩国国立中央博物馆藏高丽遗址出土中国瓷器》所载双菊纹碗与之相似。
