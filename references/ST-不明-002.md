# 北宋定窑白釉划花浪花纹水盂

- ID：ST-不明-002
- 来源文献：三台出土的白定“官”字款瓷器_景竹友
- 时代：北宋早期　出土年份：不明
- 出土地点：四川三台县煤建公司煤场
- 出土单位：煤场修建房屋挖土方时发现于一陶缸之中（“文化革命”期间）
- 完残程度：
- 器类：水盂
- 口沿：敛口
- 腹部：圆肩鼓腹，腹径9.2厘米
- 底足：圈足；足底未上釉；足与外底相连的折角处釉色泛青；足底有明显的削修痕迹；外底呈微斜平面
- 整体造型：敛口、圆肩鼓腹、圈足
- 尺寸（厘米）：高 7.5，口径 5.5，足径 4.8
- 胎质：薄白净而细腻，透光，叩声清脆　胎色：白净
- 釉色：白中呈青黄
- 施釉范围：施满釉，足底未上釉
- 釉面特征：有“泪痕”和鸡眼状釉斑；内壁、内底和外壁净洁光润
- 纹饰：外壁一周刻划四朵相连的双线浪花纹，刻划得不很规则
- 成型：　装饰技法：刻划　施釉技法：　装烧：仰烧
- 研究说明：与钱宽墓、长沙墓“官”字款白瓷官字笔划相似，但釉色大部分泛黄且出现划花，应为北宋早期定窑“官”字款瓷器。
