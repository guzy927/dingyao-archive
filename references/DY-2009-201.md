# 金代定窑白釉刻划水波双鱼纹碗

- ID：DY-2009-201
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1③：226
- 完残程度：已复原
- 器类：碗
- 口沿：薄唇较宽，敞口微侈
- 腹部：斜直腹略曲，内底下凹
- 底足：矮圈足内收，挖足较浅，器外底心微凸
- 整体造型：敞口斜直腹略曲矮圈足碗（B型），内底刻双鱼纹
- 尺寸（厘米）：高 5.3，口径 18.5，足径 6.6
- 胎质：细腻坚致，有点状凸起　胎色：白胎泛灰
- 釉色：白釉泛青灰，较光亮
- 施釉范围：满釉
- 釉面特征：器外口沿下及底部有粘连痕
- 纹饰：内底压环，压环内刻划水波双鱼纹；外壁可见拉坯所成弦纹
- 成型：拉坯成形　装饰技法：刻划花　施釉技法：　装烧：
- 研究说明：水波双鱼纹是涧西区出土器物最具代表性的刻花纹饰，多刻于碗盘碟内底。
