# 金代定窑黄釉刻花萱草纹盘

- ID：DY-2009-264
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：
- 完残程度：仅存口部及腹部，残高2.5厘米
- 器类：盘
- 口沿：尖唇，侈口
- 腹部：直腹略曲
- 底足：
- 整体造型：侈口直腹略曲矮圈足盘（B型），内腹刻圆内刻萱草纹
- 尺寸（厘米）：高 2.5，口径 ，足径 
- 胎质：坚致　胎色：白胎
- 釉色：黄釉，泛木光
- 施釉范围：内外满釉，芒口
- 釉面特征：釉面大量褐点杂质，器外口沿下有大片火刺，有棕眼；器外口沿下有刮釉痕，刮釉较浅，外腹有三道较深刻痕
- 纹饰：内腹刻圆，圆内刻萱草纹
- 成型：　装饰技法：刻花　施釉技法：刮釉（器外口沿下刮釉痕）　装烧：芒口覆烧（支圈覆烧）
- 研究说明：定窑涧西区金代后期黄釉盘标本。
- 溯源备注：黄釉盘B型标本，无图版。原文标本编号缺失（仅存“③：”）。
