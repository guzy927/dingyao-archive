# 唐末五代定窑青黄釉碗

- ID：DY-不明-078
- 来源文献：早期定窑研究_秦大树
- 时代：唐末五代前期　出土年份：不明
- 出土地点：定窑遗址（河北曲阳）
- 出土单位：
- 完残程度：
- 器类：碗
- 口沿：口更敞
- 腹部：腹更斜直
- 底足：
- 整体造型：碗
- 尺寸（厘米）：高 ，口径 ，足径 
- 胎质：粗质灰胎，夹杂大量杂质，火候高而坚实　胎色：灰
- 釉色：青黄釉
- 施釉范围：内壁及口沿处施化妆土，外壁施青釉
- 釉面特征：
- 纹饰：外壁不见锥刺纹等装饰
- 成型：　装饰技法：素面　施釉技法：　装烧：三叶形支钉作间隔具叠置明火裸烧
- 研究说明：唐末五代前期青黄釉瓷器类绝大多数为碗；与前期相比口更敞、腹更斜直。
