# 金代定窑白釉刻花菊瓣纹斗笠碗

- ID：DY-2009-203
- 来源文献：曲阳涧西区出土定窑瓷器整理与研究_孙华
- 时代：金代后期　出土年份：2009
- 出土地点：定窑遗址涧西区（曲阳涧磁村西）
- 出土单位：09JXT1⑤：17
- 完残程度：已复原
- 器类：碗
- 口沿：尖唇，敞口微侈
- 腹部：腹部斜直略曲
- 底足：小圈足，挖足较浅
- 整体造型：敞口微侈斜直腹略曲小圈足碗（C型），即斗笠碗，内壁满刻菊瓣纹
- 尺寸（厘米）：高 4.1，口径 13.1，足径 2.4
- 胎质：细腻坚致，外壁及底部粘有少量白胎　胎色：白胎
- 釉色：白釉泛灰，光亮
- 施釉范围：内外满釉，芒口
- 釉面特征：外壁积釉处可见青绿色小气泡，釉面有少量褐点杂质，有少量棕眼
- 纹饰：器内口沿下饰两道凹弦纹，内壁满刻菊瓣纹；器外拉坯所成凹弦纹较显著
- 成型：拉坯成形　装饰技法：刻花　施釉技法：　装烧：覆烧（芒口）
- 研究说明：斗笠碗是定瓷具有代表性的器型，同图案内壁印花菊纹斗笠碗在定窑遗址亦有出土。
